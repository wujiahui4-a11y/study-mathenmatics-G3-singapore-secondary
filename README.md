# study-mathenmatics-G3-singapore-secondary

## Games

### Baldi's Basics (3D)

Classic-style **Story Mode** recreation in the browser:

- [baldi.html](baldi.html) — first-person schoolhouse, 7 notebooks, You Can Think Pad, Baldi chase, exits

**Controls:** WASD move · Shift run · Mouse look · E / click interact · 1–3 inventory · Q / Space use item

Open `baldi.html` locally or via any static file server.

### Scratch project

`project.json` is a Scratch 3.0 project (see other branches for packaging tooling).
